DOWNLOAD & PLAY

Get Arena Survival

Download the full game. Run locally in your browser. No installation required.

DOWNLOAD ZIP VIEW ON GITHUB

HOW TO RUN LOCALLY

  1. Download and extract the ZIP file
  2. Open arena.html directly in your browser
  3. That's it! No server required for single-player

DEPLOY TO NEOCITIES

  1. Create account at neocities.org
  2. Upload all files (HTML, assets folder, styles.css)
  3. Your game is live at yoursite.neocities.org

RUN WITH LEADERBOARD (OPTIONAL)

  1. Install Node.js
  2. Navigate to server/ folder
  3. Run npm install && npm start
  4. Server runs on port 3001
  5. Edit API URLs in JS files to point to your server
